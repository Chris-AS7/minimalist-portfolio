# Christopher Sanders — Minimalist Portfolio

A full stack portfolio site built with React + Vite, integrated with
Supabase PostgreSQL for contact form submissions, and auto-deployed
via Vercel CI/CD.

🌐 Live site: [chrisasanders.com](https://chrisasanders.com)

---

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | React, Vite, Tailwind CSS |
| Database | Supabase (PostgreSQL) |
| Hosting | Vercel |
| Version Control | GitHub |
| Domain & Email | Hostinger |

---

## Features

- ⚡ Fast builds with Vite
- 🎨 Responsive design with Tailwind CSS
- 🌙 Dark / light mode toggle
- 📬 Contact form with Supabase PostgreSQL storage
- 🔒 Row Level Security (RLS) policies on database
- 🚀 Auto-deployment on every git push via Vercel CI/CD
- 🔑 Secure environment variable management

---

## Getting Started

1. Clone and install:
git clone https://github.com/Chris-AS7/minimalist-portfolio.git
cd minimalist-portfolio
npm install

2. Create a `.env` file:
VITE_SUPABASE_URL=your_supabase_project_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key

3. Run dev server:
npm run dev

---

## Deployment

git add .
git commit -m "your message"
git push

Vercel auto-deploys on every push. No manual steps needed.
